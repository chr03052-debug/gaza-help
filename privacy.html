プライバシー / الخصوصية

日本語

このサイトはアカウント作成を求めず、氏名・電話番号・現在地を入力する欄もありません。運営者が追加した広告、アクセス解析、追跡ツールはありません。

オフライン表示と言語設定のため、表示情報、選択言語、最終更新時刻をブラウザー内に保存します。ブラウザーのサイトデータを削除すると消去できます。

サイトはGitHub Pagesで公開されています。GitHubは運用・安全確保のため、IPアドレスやリクエスト情報を処理する場合があります。

公式情報源へのリンクを開くと、その外部サイトのプライバシーポリシーが適用されます。

العربية

لا يطلب هذا الموقع إنشاء حساب ولا يحتوي على حقول لإدخال الاسم أو رقم الهاتف أو الموقع. ولا يضيف المشغّل إعلانات أو أدوات تحليل أو تتبع.

قد يحفظ المتصفح معلومات العرض واللغة المختارة ووقت آخر تحديث للعمل دون اتصال. يمكن حذفها بمسح بيانات الموقع من المتصفح.

تتم الاستضافة عبر GitHub Pages، وقد تعالج GitHub عنوان IP ومعلومات الطلب لأغراض التشغيل والأمان.

عند فتح رابط لمصدر رسمي خارجي، تسري سياسة الخصوصية لذلك الموقع.
