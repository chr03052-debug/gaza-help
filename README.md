# gaza-help

ガザ危機の影響を受ける人が、公開されている公式情報源を確認しやすくするための、独立した非公式のWebサイトです。低データ利用と、登録なしでの閲覧を意識しています。

## 公開サイト

https://chr03052-debug.github.io/gaza-help/

## 重要な注意

- このサイトは、OCHA・WHO・WFP・UNRWAが運営または承認しているものではありません。
- 掲載されている支援やサービスは、現在利用できない場合があります。場所や経路が安全とは限りません。
- 判断や移動の前に、必ず最新の公式情報と現地状況を確認してください。
- 緊急通報や個別の医療判断を行うためのサービスではありません。
- 人や機関の位置を追跡する機能や、機微な位置情報を公開する機能は設けていません。

## 情報源と更新方針

- 掲載データは `data.json` で管理し、各項目から公開された公式情報源へ確認できるようにしています。
- 公式情報源の一覧と注意事項は [sources.html](./sources.html) に掲載しています。
- GitHub Actionsは毎日、掲載された公式URLへ到達できるかだけを確認します。
- 自動監視の成功は、掲載内容の最新性や現地サービスの継続を保証しません。
- サイト本体と `data.json` は自動更新しません。
- 情報を変更する場合は公式情報源と照合し、1項目ずつ変更して公開後に確認します。
- 運用方法と点検履歴は [.github/MAINTENANCE.md](./.github/MAINTENANCE.md) に記録します。

## プライバシー

このサイトは、アカウント作成や氏名・電話番号・現在地の入力を求めません。オフライン表示や設定保存のため、ブラウザ内に表示用データなどを保存することがあります。詳しくは [privacy.html](./privacy.html) を確認してください。

## 主なファイル

- `index.html` — トップページ
- `app.js` — 表示、検索、言語切替など
- `data.json` — 掲載情報と公式情報源
- `sources.html` — 情報源と安全上の注意
- `privacy.html` — プライバシー説明
- `.github/workflows/monitor-official-sources.yml` — 公式URLの自動到達確認
- `.github/MAINTENANCE.md` — 月次点検の手順と記録

## 意見・修正提案

不足している説明、分かりにくい点、安全上の懸念、公式情報源の変更に気づいた場合は、[GitHub Issues](https://github.com/chr03052-debug/gaza-help/issues) で知らせてください。

氏名、電話番号、正確な現在地などの個人情報や、公開すべきでない機微な情報は投稿しないでください。
